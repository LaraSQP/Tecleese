# Tecléese

Read something interesting while typing along.

A simple, mobile-first, typing practice website.

No tests, no timers, no scores, no ads, no gimmicks.

Just start reading/typing anywhere.


**[https://larasqp.github.io/Tecleese/](https://larasqp.github.io/Tecleese/)**


## Features

* A small but reasonable collection of texts to practice with
* Visual indication of correct and incorrect characters
* Adjustable text size
* On-screen keyboard option
* Resume where left off
* Mobile-friendly layout

The site is hosted using GitHub Pages.
